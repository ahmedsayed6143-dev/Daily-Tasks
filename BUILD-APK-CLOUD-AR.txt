بناء APK أونلاين من غير Android Studio
======================================

المشروع يحتوي على Workflow لبناء APK باستخدام GitHub Actions.
لا تحتاج إلى تثبيت Android Studio أو Android SDK على جهازك، لكن تحتاج إلى حساب GitHub واتصال إنترنت.

الخطوات:
1) أنشئ مستودعًا جديدًا على https://github.com/new واجعله Public لتجنب قيود دقائق Actions للحسابات المجانية.
2) ارفع جميع ملفات ومجلدات هذا المشروع إلى المستودع، مع الحفاظ على المجلد .github/workflows وملف build-apk.yml داخله.
3) افتح تبويب Actions في المستودع، ثم وافق على تفعيل Actions إذا طلب ذلك.
4) افتح عملية Build Daily Tasks APK، وانتظر حتى تصبح خضراء (Success).
5) افتح العملية الناجحة وانزل إلى Artifacts، ثم نزّل Daily-Tasks-APK.zip.
6) فك ضغط الملف؛ ستجد app-debug.apk. انقله إلى الهاتف وثبّته بعد السماح بالتثبيت من هذا المصدر عند الطلب.

ملاحظة: هذه نسخة Debug للتجربة والتثبيت الشخصي. لا تشارك ملف المشروع أو المستودع إذا كنت لا تريد أن يكون مصدر الموقع عامًا، لأن المستودع العام يمكن لأي شخص رؤيته.
