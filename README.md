# Daily Tasks for Android 📱

A clean and easy-to-use **Daily Tasks** and **To-Do List** Android application designed to help you organize your day, manage your schedule, and stay productive on the go.

## ✨ Features (المميزات)
- **Add & Manage Tasks:** Easily create, edit, and delete daily tasks from your phone.
- **Task Status:** Mark tasks as completed to track your daily progress.
- **Native Android Wrapper:** Smooth, responsive, and distraction-free design tailored for Android devices.
- **Ready APK:** Easy to install directly on any Android phone.

## 🛠️ Built With (التقنيات المستخدمة)
- **HTML, CSS & JavaScript** (User Interface)
- **Java & Android WebView** (Native Android App)

## 🚀 How to Install & Run (طريقة التثبيت والتشغيل)

### Option 1: Install APK directly (للمستخدمين)
1. Go to the **[Releases](https://github.com/ahmedsayed6143-dev/Daily-Tasks-Android/releases)** section on the right.
2. Download the latest `.apk` file to your Android device.
3. Open the file and allow installation from unknown sources if prompted.

### Option 2: Build from Source Code (للمطورين)
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder in **Android Studio** and let Gradle sync the files.
3. Build and run the app on an emulator or physical Android device.
